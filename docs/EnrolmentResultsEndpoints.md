# Enrolment and Results Endpoints

## Enrolments

- POST /api/events/{eventId}/enrolments
- GET /api/events/{eventId}/enrolments

Participants can enrol in events by selecting an event category.

## Results

- POST /api/enrolments/{enrolmentId}/result
- GET /api/results/me

Organisers can capture race results and participants can view their personal results.
